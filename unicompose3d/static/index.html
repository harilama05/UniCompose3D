Get started in a few steps

  1. Add base object A and object B using images or existing 3D models.
  2. Remove the background, check the complete object, then create the 3D model. Assign camera views when using multiple images.
  3. Enter a short request and click Compose. AI asks for clarification when your intent is ambiguous.
  4. Use Move, Rotate, and Scale. Press W/E/R to switch tools.
  5. Save a project ZIP to reopen it later, or export GLB.

Server-side scenes last only as long as the Kaggle data. Download your project ZIP before ending the session.

Unseen surfaces may be inferred by AI. Automatic composition and soft deformation are for visualization; natural results are not guaranteed for every object pair.
