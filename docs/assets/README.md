# Demo assets

- `studio.png`: the actual English Studio rendered in a browser with procedural table/vase geometry. Opened directly from the free procedural demo, without model inference or API calls. Reproduce with python tools/capture_demo.py after installing Playwright Chromium.
- `composition.png`: an actual render of reconstructed head/cap geometry from a development composition replay. It demonstrates an editable 3D scene, not a new live Luna run or a physical fit guarantee.

No input photos, private GLB models, session links, keys, or diagnostic bundles are distributed here. Demonstration renders are illustrative; source object designs and likenesses are not licensed as part of the MIT software. Replace the reconstructed-object illustration if your publication requires separately cleared source assets.
